Chapter IV — The Archive

01

The Same Bytes, Stored Once

Go · Gin · PostgreSQL · Redis · RabbitMQ · S3

HashVault hashes every upload with SHA-256 and resolves identical bytes to a single S3 key. Reference counts move atomically in SQL; the object is purged only when the last reference drops to zero.

A two-token auth scheme pairs short-lived JWTs with opaque refresh tokens, stored only as hashes — a stolen token cannot be replayed. Presigned URLs keep file bytes off the Go server entirely.

Plate 01 — the dedup check happens before a single byte leaves the client.

02

Six Services, One Conversation

Next.js · Express · MongoDB · Redis · RabbitMQ · Kafka

A real-time chat platform across six microservices, with a Socket.IO gateway and Traefik in front of them. Auth runs on JWT RS256 dual tokens, OTP email verification, and OAuth guarded by CSRF state.

Chat events route through RabbitMQ and Kafka into an AI moderation pipeline; Redis sliding-window aggregation stops a single message from being flagged out of context.

Plate 02 — a pattern of messages is judged, never one taken alone.
