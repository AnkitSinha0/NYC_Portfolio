Cloud Storage PlatformSheet 01 / 03

HashVault

Go · Gin · PostgreSQL · Redis · RabbitMQ · AWS S3 / MinIO

Two users upload the same file. Most systems store it twice. HashVault hashes the content with SHA-256 and resolves identical bytes to a single S3 key — reference counts move atomically in SQL, and the object is purged only when the last reference drops to zero.

A two-token auth scheme pairs short-lived JWTs with opaque refresh tokens, stored only as hashes in Redis. Presigned URLs keep file bytes off the Go server entirely — it stays on the control plane.

Real-Time Chat PlatformSheet 02 / 03

Konnect

Next.js · Express · MongoDB · Redis · RabbitMQ · Kafka

A real-time chat platform architected across six microservices, with a Socket.IO WebSocket gateway and a Traefik reverse proxy in front of them. Auth runs on JWT RS256 dual tokens, OTP email verification, and OAuth guarded by CSRF state.

Chat events route through RabbitMQ and Kafka into an AI moderation pipeline. Redis sliding-window aggregation judges a pattern of messages, never one taken out of context.
