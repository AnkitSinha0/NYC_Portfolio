HashVault

Distributed Storage for a Less Centralized Internet.

By Ankit Sinha

HashVault is a distributed cloud storage system built with Go, designed for durability, efficiency and developer control. It deduplicates files using SHA-256, stores metadata in PostgreSQL, and uses S3 for scalable object storage.

A personal project to understand distributed systems, build real infrastructure skills, and create something I would actually use.

KEY FEATURES
  • SHA-256 Deduplication
  • Presigned Upload URLs
  • JWT Auth + Refresh Tokens
  • Background Workers
  • Dockerized (Compose)
SCALING VISION
  • Multi-region support
  • Object versioning
  • Access control & sharing
  • Monitoring (Prometheus + Grafana)

Component Details

API Server /gin

Handles auth, metadata ops, presigned URL generation.

Worker

Processes async jobs: thumbnailing, metadata indexing, cleanup.

Storage Layer

S3-compatible. Swappable between MinIO (local) and AWS S3 (production).
